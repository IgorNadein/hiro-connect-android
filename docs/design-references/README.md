# Референсы интерфейса HiRo Connect

Визуальная основа, согласованная при обсуждении интерфейса. Изображения созданы как референсы, а не как точное описание существующих функций; имена и номера на них вымышлены.

- [Светлая и тёмная темы](themes.png): спокойный интерфейс, нижняя навигация и кнопка набора.
- [Список звонков](unified-calls.png): выбран объединённый вариант слева. Текущие и ожидающие звонки располагаются перед историей; статусы обозначаются словами и цветом.
- [Поиск и набор номера](search-and-dialpad.png): поиск и меню сверху, цифровая клавиатура открывается поверх списка.

Порядок разделов и действия с текущими звонками должны учитывать фактические возможности приложения и доступ пользователя. Место списка сотрудников ещё обсуждается.

- [Главный экран в стиле One UI](one-ui-calls.png): выбранный референс без свёрнутого собственного звонка; стрелка исходящего вызова на изображении нарисована неверно. Оформление текущего звонка обсуждается отдельно.
